# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability or for output that may expose credentials. Use
GitHub's private vulnerability reporting feature when it is enabled for this repository.

Include the affected version, a minimal reproduction, and the expected impact. Remove repository
URLs, tokens, and environment-file contents before sharing logs.

## Supported versions

Until the first stable release, only the latest revision on `main` receives security fixes.
