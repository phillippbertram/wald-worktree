wald prepares Git worktrees for real projects. Keep an editor and unfinished changes open for one
task while another task starts in its own folder.

- [Get started](getting-started.md) to install wald and create a worktree in a project you already use.
- [Why worktrees?](worktrees.md) for a hotfix example and a short explanation of what Git shares.
- [Parallel coding agents](agent-workflows.md) to give two tasks separate files and staging areas.
- [Project setup and hooks](project-setup.md) to automate setup and checks around worktree creation
  and removal.

Look up any command in the [CLI reference](cli-reference.md) or explore the
[configuration reference](configuration.md).

## Why wald?

The name comes from the German word *Wald*, meaning “forest”. It’s pronounced /valt/, with a **v**
sound at the start and a **t** at the end. Several worktrees share one Git repository.
[Cambridge Dictionary](https://dictionary.cambridge.org/us/dictionary/german-english/wald)
